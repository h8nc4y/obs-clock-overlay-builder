# Cost Guard

Codex may continue through local edits, tests, free dependency installs, branch/commit/push, GitHub issue and PR work, review fixes, merge, and Cloudflare deploys for this repository when no new cost is expected.

Stop before any operation that may incur monetary cost, enable or increase paid service usage, transmit secrets/tokens/OAuth credentials/real user or customer data externally, or exceed Cloudflare free or included quotas through large storage, egress, compute, database, queue, workflow, AI, or gateway usage.

If stopping, report:

- exact operation
- why it is needed
- cheaper local/mock/free alternative
- estimated cost in JPY
- USD/JPY assumption or source
- pricing basis
- recommended approval wording
- safest next command after approval

Use approximately 160 JPY per USD only when no fresher exchange rate is available, and mark that rate as unverified.

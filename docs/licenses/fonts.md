# Font License Notes

No font files are bundled in this repository.

The editor lists these font names as candidates only:

- Noto Sans JP
- M PLUS Rounded 1c
- Zen Maru Gothic
- Kosugi Maru
- Kiwi Maru
- Mochiy Pop One
- Hachi Maru Pop
- Yusei Magic
- Dela Gothic One
- Poppins
- Inter
- Roboto Mono

If you later self-host any font files, verify the current official license from the font distributor before adding the files. Keep a copy of the license text or a clear license notice in this directory.

The generated OBS URL stores only the font-family string. The overlay applies it as an escaped CSS string with system fallbacks, so missing fonts do not break rendering.

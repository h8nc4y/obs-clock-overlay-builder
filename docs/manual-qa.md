1. `npm run dev` を実行する。
2. `http://localhost:4173/` を開く。
3. `http://localhost:4173/clock/` と `http://localhost:4173/clock` を開く。

## Builder

- 全18テンプレートをすべてクリックし、ライブプレビューへ即時反映される。
- 背景確認を `透過チェッカー`、`明るい背景`、`暗い背景`、`任意色` へ切り替えられる。
- プレビュー背景の各選択肢は44px以上の押しやすい領域になり、ラベル全体を押して切り替えられる。
- プレビュー背景のラベルはhoverとfocus-withinで反応が見え、キーボード操作中の位置が分かる。
- 文字色、背景色、不透明度、角丸、余白、文字サイズ、文字間隔、行間、太さ、影、縁取り、枠線が反映される。
- デジタル時計で `秒を表示` と `秒を小さく表示` をオンにすると、ライブプレビューは本体時刻が `HH:MM`、秒が小さい別スロットで表示される。
- `秒を表示`・`日付を表示`・`曜日を表示` を切り替えると、STEP1のテンプレートカードのミニ時計も現在の表示設定に追従する(オフにすると消え、オンにすると出る)。カードをクリックした結果が、そのカードのミニプレビューと一致する。
- `Studio Live` / `Night Studio` を選び `秒を表示`+`秒を小さく表示` をオンにすると、時刻下のアクセント下線が小さい秒の右端まで伸びる。秒なし/小さい秒オフでは下線幅が変更前と同じに見える。
- コントラストが低い設定で警告が表示される。
- 生成URLが `/clock/?c=...` 形式で、コピーできる。
- `デフォルト値を省略して短くする` をオンにしても、時計画面で同じ表示になる。
- 推奨幅・高さが表示され、テンプレートやサイズ変更後に更新される。

## Import And URL Compatibility

- 生成URL全体をインポートできる。
- `?c=...` のクエリ文字列をインポートできる。
- `c` パラメータの値だけをインポートできる。
- JSONとURLエンコード済みJSONをインポートできる。
- `?tz=UTC&hour12=1&seconds=0&date=1&weekday=1&font=Poppins&theme=soda` のようなフラットGETパラメータで時計画面が表示される。
- 壊れた `c`、壊れたJSON、不正timezone、不正色、不正数値では初期値または安全な範囲へ戻る。
- localStorageを削除しても、生成URLだけで同じ表示になる。
- localStorageへ壊れたJSONが入っていても編集画面が起動する。

## OBS Clock Surface

- `/clock/` は時計だけを表示し、編集UIや余分な本文が出ない。
- ページ背景は透明で、`body` の余白がない。
- 24時間の `HH:MM:SS` がデフォルトで毎秒更新される。
- `Asia/Tokyo` がデフォルトタイムゾーン。
- PCのシステム時刻を数分ずらしても、`/clock/` はサーバー時刻へ自動補正され、ほぼ正しい時刻を表示する(同一オリジン `/api/defaults` の `Date` ヘッダを使用)。
- ネットワークを遮断すると補正できず、PCのシステム時刻にフォールバックして時計は止まらず動き続ける。
- 12時間表記、秒なし、小さい秒表示、日付あり、曜日あり、長いラベル、背景不透明度0をそれぞれ確認する。
- 小さいviewport、横長viewport、縦長viewportで時計が意図せず切れないか確認する。切れる場合はOBS側の幅・高さを推奨値より大きめにする。
- Neon HUDなど発光が強いテンプレートで、通常ブラウザとOBSの両方で上下左右の発光が切れないことを確認する。
- OBSでブラウザソースに生成URLを貼り、推奨幅・高さを入力して表示される。
- localStorageを削除した別ブラウザ/シークレットウィンドウでも、`Mono Sub` の `/clock/?c=...` URLだけで小さい秒表示が再現される。
- OBSで表示/非表示を切り替えても、再表示後の次tickで現在時刻になる。

## OBS実機確認

OBS実機では、編集画面ではなく生成URLそのものをブラウザソースに貼って確認する。

### 事前準備

1. `npm run dev` を起動する。
2. 編集画面 `http://localhost:4173/` を開く。
3. 任意のテンプレートを選び、`OBS用URL` の生成URLをコピーする。
4. `時計だけを確認` で時計だけの画面を開き、背景が透明で編集UIが出ないことを確認する。
5. 推奨幅と推奨高さをメモする。

### OBS設定

1. OBSで `ソース` の `+` を押す。
2. `ブラウザ` を選ぶ。
3. URL欄へ生成URLを貼る。
4. 幅へ推奨幅、高さへ推奨高さを入力する。
5. 背景を透過したい場合、OBS側の背景色やカスタムCSSで白背景を足していないことを確認する。
6. 表示が切れる場合は、幅と高さを推奨値より20pxから80pxほど大きくする。

### 合格基準

- 時計だけが表示され、編集画面のボタンや説明文が出ない。
- 背景が透明で、配信画面の映像や画像の上に時計だけが重なる。
- 秒表示ありの設定では、秒が毎秒進む。
- OBSのソースを非表示から再表示したあと、1秒以内に現在時刻へ戻る。
- 生成URLをOBSに貼り直しても同じ見た目になる。
- ラベル、日付、曜日、12時間表示、秒なしなど、編集画面で選んだ設定が反映される。
- OBS上で文字が切れず、配信画面の主要UIを隠しすぎない。

### 失敗時の切り分け

- 背景が白い: 生成URLを通常ブラウザで開き、透明背景か確認する。通常ブラウザで透明なら、OBSのブラウザソース設定、カスタムCSS、シーン背景を確認する。
- 文字や発光が切れる: まず生成URLと推奨幅・高さが最新か確認し、それでも切れる場合はOBSの幅と高さを大きくする。影、縁取り、太字、長いラベルは必要サイズが増える。
- 時計が動かない: URLを通常ブラウザで開き、秒が進むか確認する。通常ブラウザで動くなら、OBSのブラウザソースを再読み込みする。
- 見た目が違う: OBSを動かすPCに同じフォントが入っているか確認する。未インストールなら別フォントへ置き換える。
- 設定が戻らない: OBSに貼ったURLが `/clock/?c=...` 形式か確認する。編集画面のlocalStorageではなく、生成URLが再現の正。
- ローカルURLがOBSで開けない: OBSとローカルサーバーが同じPC上で動いているか、`npm run dev` が起動中か確認する。

## Fonts

- `PC内フォントを読み込む` はユーザー操作後だけ実行される。
- ブラウザから許可を求められたら、PC内フォント名を読むことを許可してください、という案内が表示される。
- 許可後に一覧が空でも、手入力フォント名へOBSを動かすPCで使える正式なフォント名を入れられることが分かる。
- `queryLocalFonts` 非対応環境では、手入力案内が表示される。
- 権限拒否時も編集画面が壊れない。
- フォント欄の説明で、フォントファイルは同梱されず、OBSを動かすPCに同じフォントが必要なことが分かる。
- `LightNovelPopV2 V2` は `ラノベPOP v2（LightNovelPopV2 V2）` のように、日本語名を先にした表示になる。
- フォント一覧の日本語表示名は補助で、表示名ではなく、OBSで実際に参照するフォント名がURLへ保存されることが分かる。

- OBSを動かすPCに無いフォント名を指定した場合、system fallbackで表示される。
- 同じ生成URLでも、OBSを動かすPCに対象フォントが無い場合は別の書体に見える。配信に使うPCで最後に確認する。

## プレビューのピン留め / フロートの確認 (v1.2〜1.3・編集画面専用)

これらはエディタのプレビュー表示の挙動で、`/clock/?c=...` の出力(OBS再現性)には影響しない。

- ライブプレビューの箱の右上に固定ピン(📌・アイコンのみの丸ボタン)があり、押すと固定/解除が切り替わること。固定中はアクセント塗り、未固定は白枠＋ピンが少し傾く。ホバーで「プレビューを固定する/固定を外す」の説明(title)が出ること。
- デスクトップ(幅1101px以上)で固定中、右の設定を **「こだわり」にして最後までスクロールしても**、左の時計プレビューが画面上部に追従し続けること(途中で止まらない)。
- スマホ/タブレット(幅1100px以下)で固定中、ページを下へスクロールして実プレビューが画面上端から外れると、その実物のプレビューが**実寸のまま**画面上部にフロートし、上へ戻すとフロートが解除されること。最上部では時計が二重に見えないこと(点滅しないこと)。
- 固定ピンの状態はリロード後も維持されること(localStorage、`/clock/?c=...` には含まれない)。
## 表示設定の細分化(日付3軸・曜日括弧・AM/PM位置)

- こだわり調整モードの「表示」で、3カラム行が「ラベル位置」「曜日表記」「日付の区切り」の順に見えること。
- 「日付の区切り」で `/ 区切り(2026/07/03)`、`- 区切り(2026-07-03)`、`日本語(2026年7月3日)` を切り替え、年表示とゼロ埋めのチェック有無がプレビューと生成URLへ反映されること。
- 「曜日を（）で囲む」をONにし、日本語曜日は `（金）`、英語曜日は `(Fri)` のように括弧が変わること。
- 「12時間表示にする」をOFFにしたとき「AM/PMを時刻の前にする」が無効化され、ONに戻すと `AM 09:51` のような前置表示がプレビュー、フリップ時計、共有PNGに反映されること。
- 旧形式の共有URL(`dateFormat` 入りの `?c=...` や `?dateFormat=monthDay` などのフラットGET)を開いても、以前と同じ日付表示(`2026/07/03` / `2026-07-03` / `07/03` / `2026年7月3日`)のまま変わらないこと。

## 文字調整グループ(v1.7.0)

- こだわりタブに「文字調整：ラベル」「文字調整：日付」「文字調整：時刻」の3グループがこの順で表示されること。
- 12時間表示ONで AM/PM が時刻の約半分(既定0.55倍)で表示され、「AM/PMの大きさ」スライダーで変わること。24時間表示中はスライダーが無効になること。パタパタ時計では AM/PM がめくれない静的表示になること。
- 「曜日との間隔」が既定0で `2026/7/3（金）` のように密着し、スライダーで間隔が開くこと。共有PNGでも同じ間隔になること。
- ラベル/日付の「太さ・間隔を個別に調整する」をONにするとスライダーが現れて反映され、OFFに戻すと従来の見た目(連動)へ戻ること。個別調整した値は生成URLに保存され、`/clock/?c=...` で再現されること。
- 個別調整を一度も触っていない場合(連動のまま)、v1.6.0以前のURLと同じ太さ・間隔で表示されること(AM/PMの大きさと曜日間隔の既定変更を除く)。
- 「秒を表示」「日付を表示」等に加え、日付の区切り・曜日括弧・AM/PM設定を変えたときも、STEP1のテンプレートカードが追従すること。

STEP 3

OBSに貼る

コピーしたURLを貼るだけで、同じ時計がそのまま出ます。

  1. URLをコピー 左の「OBS用URLをコピー」を押します。
  2. OBSでブラウザソースを追加して貼り付け ソース追加 → ブラウザ → URL欄に貼り付けます。
  3. 幅と高さを推奨値に 推奨幅 229px / 推奨高さ 58px を入力します。

よくある質問

背景が白くなる

時計の画面そのものは透明背景です。OBS側のブラウザソース設定やカスタムCSS、プレビュー背景の設定を確認してください。

フォントが反映されない

OBSを動かすPCに同じフォントが入っている必要があります。フォントが無い場合は、近い標準フォントで表示されます。

実験室(キーワード反応オーバーレイ)

コメントのキーワードに反応するオーバーレイを試作中です。時計のURLや表示には影響しません。

フォントファイルは同梱していません。URLにはフォント名だけを保存します。
